Simulation Details

What each Gatling scenario validates and which performance gates apply.

SessionsSimulation.scala

Load test for saved session retrieval used by dashboards and selectors.

Endpoint
GET /api/sessions
Gate
P95 below 500 ms and success rate above 95%
Pass means
Session lists remain fast under concurrent access.

DuringMergeSimulation.scala

Performance test for aligning HR/HRV and SpO2/pulse timeline telemetry.

Endpoint
POST /api/during_merge
Gate
P95 below 1000 ms and failed requests below 10%
Pass means
The merge engine remains responsive for telemetry timelines.

RunAnalysisSimulation.scala

Benchmark for AI scoring, wellness flags, features and timeline output.

Endpoint
POST /api/run_analysis
Gate
P95 below 1500 ms and success rate above 95%
Pass means
AI output remains interactive for dashboards and QA.

UploadCsvSimulation.scala

Upload and parser performance test for SpO2/pulse timeline telemetry.

Endpoint
POST /upload_csv
Gate
P95 below 2000 ms and controlled parser failures
Pass means
CSV telemetry ingestion remains stable.

UploadFitSimulation.scala

Upload and parser performance test for HR/HRV timeline telemetry.

Endpoint
POST /upload_fit
Gate
P95 below 2500 ms and controlled parser failures
Pass means
FIT ingestion path remains responsive.

Architecture And CLI

Local Gatling structure, command entry points and CI/CD integration.

Gatling Structure

tests/performance/gatling/
|-- pom.xml
`-- src/test/scala/corelabtech/
    |-- BaseSimulation.scala
    |-- SessionsSimulation.scala
    |-- DuringMergeSimulation.scala
    |-- RunAnalysisSimulation.scala
    |-- UploadCsvSimulation.scala
    `-- UploadFitSimulation.scala

CLI Commands

cd tests/performance/gatling

mvn gatling:test -Dgatling.simulationClass=corelabtech.SessionsSimulation
mvn gatling:test -Dgatling.simulationClass=corelabtech.DuringMergeSimulation
mvn gatling:test -Dgatling.simulationClass=corelabtech.RunAnalysisSimulation
mvn gatling:test -Dgatling.simulationClass=corelabtech.UploadCsvSimulation
mvn gatling:test -Dgatling.simulationClass=corelabtech.UploadFitSimulation
